02

Como publicar uma alteração

  1. Faço a alteração no código e gero um .zip da pasta correspondente.
  2. No Gerenciador de Arquivos do cPanel, entrar dentro da pasta de destino exata antes de qualquer coisa — ex.: public_html/discursiva-fepese-itajai-sc/, ou public_html/ raiz pra home da mentoria.
  3. Clicar em Carregar estando dentro dessa pasta e subir o zip ali.
  4. Clicar com o botão direito no zip → Extrair, confirmando a sobrescrita do index.html e assets/ existentes.
  5. Conferir em aba anônima — evita o cache do navegador mostrar a versão antiga.
Cuidado: extrair o zip no nível errado (ex. na raiz do public_html/ quando era pra estar dentro de uma subpasta) já sobrescreveu por engano o index.html da home com o conteúdo de outra página. Sempre confirmar em qual pasta está antes de extrair.

Script de rastreamento de UTM

Adicionado só na home da mentoria (mentoria-estude-ambiental/index.html, antes do </body>) — propaga utm_source, utm_medium, utm_campaign, utm_term, utm_content, fbclid e gclid da URL da página pro link do formulário de aplicação, antes do clique. Não muda nada visualmente. Não foi adicionado nas páginas de Discursiva nem nas institucionais — só onde tem o link do formulário.

(function () {
  var FORM_URL = 'estude-ambiental-form.vercel.app'
  var UTM_KEYS = ['utm_source','utm_medium','utm_campaign','utm_term','utm_content','fbclid','gclid']
  var src = new URLSearchParams(window.location.search)
  if (!UTM_KEYS.some(function (k) { return src.get(k) })) return
  document.querySelectorAll('a[href*="' + FORM_URL + '"]').forEach(function (el) {
    var url = new URL(el.href)
    UTM_KEYS.forEach(function (k) { var v = src.get(k); if (v) url.searchParams.set(k, v) })
    el.href = url.toString()
  })
})()
